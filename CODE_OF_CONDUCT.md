# Code of Conduct

## Our standard

This project is a technical workspace. Be direct about the work and respectful toward the people doing it.

Expected behavior:

- critique ideas, evidence, and code rather than individuals;
- assume uncertainty is honest, and ask for missing context;
- make room for different experience levels, languages, and tools;
- keep reviews specific, actionable, and proportionate;
- respect privacy and do not publish another person’s data, credentials, or private project details.

Unacceptable behavior:

- harassment, threats, discrimination, or sexualized attention;
- personal attacks, repeated bad-faith argument, or deliberate humiliation;
- publishing private information without permission;
- spam, fabricated evidence, or misrepresenting another person’s work;
- pressuring maintainers or contributors to weaken security or verification controls.

## Scope

This code applies in repository spaces: issues, pull requests, discussions, reviews, and project-related conversations. It does not give maintainers authority over unrelated personal conduct.

## Reporting

For a conduct concern, contact the maintainer privately using the contact information on [@Hangtu’s GitHub profile](https://github.com/Hangtu). Do not post sensitive details in a public issue.

For platform abuse, use GitHub’s own reporting tools. For a security vulnerability, follow [SECURITY.md](SECURITY.md) instead; that process is private and better suited to technical reports.

## Enforcement

Maintainers may edit or remove content, close threads, request a pause, or restrict participation when behavior is unsafe or disrupts the project. Decisions should be proportionate to the behavior and may be explained privately where privacy is a concern. There is no promise of a specific response time or appeal process.
